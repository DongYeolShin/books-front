

# 1. 개발 목적
- 장바구니 리스트에서 수량 변경
- 장바구니 리스트에서 도서의 삭제


# 2. 기능 설명
## 2.1 도서의 수량 변경
- 선택된 도서의 수량 변경

### 2.1.1 서버 API 정보 
- end-point : /api/v1/carts
- method : patch
- 파라메터 양식 : JSON
- 파라메터 예시 :
```
  { "bookId" : "BOOK001",  "quantity" : 1 }
```
- 결과 데이터
    - 성공 시 : { "code" : 200 , "message" : "수정되었습니다."}
    - 실패 시 : { "code" : 500 , "message" : "수정이 실패되었습니다."}




## 2.2 도서의 삭제
- 선택된 도서를 장바구니에서 삭제

### 2.2.1 서버 API 정보 
- end-point : /api/v1/carts/{bookId}
- method : delete
- 결과 데이터
    - 성공 시 : { "code" : 200 , "message" : "삭제되었습니다."}
    - 실패 시 : { "code" : 500 , "message" : "삭제 실패되었습니다."}


# 3. 공통사항
- 수량 변경  및 삭제 완료 전까지 로딩바 노출 
- 서버 API 성공 시 수량 변경
- 서버 API 성공 시 도서 삭제 후 화면 업데이트 
- 서버 API 실패 시 오류 메시지 출력
